# LinkedIn Job Scraper Setup Guide (for VS Code)

## 1️⃣ Requirements
- Python 3.9 or later
- Google Chrome
- Visual Studio Code

## 2️⃣ Create the project folder
Example:
C:\Users\YOUR_USER\Documents\LinkedinJobScraper\

Place inside:
- LinkedinJobsScraperAdvance.py
- requirements.txt

## 3️⃣ Open the folder in VS Code
File → Open Folder → select your folder.

## 4️⃣ Create and activate a virtual environment

Open VS Code terminal:
```
python -m venv venv
venv\Scripts\activate
```
You’ll see `(venv)` at the beginning of your terminal line.

## 5️⃣ Install the dependencies
```
pip install -r requirements.txt
```

## 6️⃣ Run the script
```
python LinkedinJobsScraperAdvance.py
```

When Chrome opens:
1. Log in to LinkedIn manually.
2. Go back to the terminal and press Enter.
3. Wait while jobs load and descriptions are scraped.

A CSV file will be created in the same folder, e.g.:
```
linkedin_jobs_Data_Analyst_Remote_2_3_week.csv
```

## 7️⃣ Optional Chrome settings
- Incognito: already enabled (`--incognito`)
- Headless (no window): uncomment `options.add_argument("--headless")`

## 💡 Tips
- Adjust `JOB_KEYWORD`, `JOB_LOCATION`, `EXPERIENCE_LEVELS`, and `DATE_POSTED` in the config section.
- Use `"24h"`, `"week"`, or `"month"` for the `DATE_POSTED` filter.
- You can re-run the script anytime with different parameters.
